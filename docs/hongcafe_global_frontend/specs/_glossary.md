# 용어집 (Glossary)

> 화면설계서에서 사용되는 용어와 프론트엔드 프로젝트 매핑

## 플랫폼 / 리전

| 기획서 용어 | 설명 | 프론트엔드 매핑 |
|-----------|------|---------------|
| KR | 한국 플랫폼 (기존 홍카페) | locale: `ko` |
| JP | 일본 플랫폼 (글로벌 통합버전) | locale: `ja` |
| US | 미국 플랫폼 (글로벌 통합버전) | locale: `en` |
| 통합버전 | JP+US 우선 개발 대상 | 이 프로젝트의 주 개발 범위 |
| 공통 | KR/JP/US 모두 적용 | 모든 locale에 동일 구현 |
| 국가별 | 국가마다 다른 항목 | 조건부 렌더링 또는 별도 컴포넌트 |

## 사용자 유형

| 기획서 용어 | 설명 | 인증 상태 |
|-----------|------|---------|
| 비 로그인 | 미인증 사용자 | 로그인 필요 기능 접근 시 로그인 페이지로 리다이렉트 |
| 회원 | 일반 사용자 (내담자) | 로그인 완료, 상담 이용 가능 |
| 내담자 | 상담을 받는 회원 | = 회원 (상담 컨텍스트) |
| 상담사 | 상담을 제공하는 전문가 | 상담사 등록 완료, 상담사 마이메뉴 접근 가능 |
| 파트너 | 제휴 상담사 | 특별 배지 표시 |
| 신규 | 최근 등록 상담사 | 특별 배지 표시 |

| 상담가능 | 상담사 상태: 접속 중, 상담 가능 | 상태 표시 UI |
