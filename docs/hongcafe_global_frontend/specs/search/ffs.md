## 1. 개요

| 항목 | 내용 |
|------|------|
| 도메인 | 검색 (Search) |
| 사용자 목표 | 상담사명/고유번호 또는 후기 내용으로 검색하여 원하는 상담사나 후기를 빠르게 찾는다 |
| 퍼블리싱 상태 | ❌ 미구현 |
| 기능 연동 상태 | 미연동 |
| i18n 네임스페이스 | `search` |
| 지원 로케일 | `en`, `ko`, `ja` |
| 뷰포트 기준 | 모바일 390x844 (Figma 핸드오프 360px 시안, 구현 PC 최대 430px — `app/[locale]/layout.js`의 SSOT wrapper `max-w-[43rem]`) |
| 슬라이드 수 | 20장 |

### 도메인 흐름 요약

```
검색 (/search)
  ├── [탭: 상담사] 상담사 검색 (S260~S267)
  │     ├── 검색창 (상담사명 또는 고유번호)
  │     ├── 최근검색어 (전체삭제, 개별삭제)
  │     ├── 자주상담한 상담사 리스트
  │     ├── 상담분야 펼침/접힘 (연애운, 짝사랑, 궁합 ...)
  │     ├── 상담스타일 펼침/접힘 (정확해요, 편안해요 ...)
  │     ├── 자동완성 드롭다운
  │     ├── 검색결과 (총 N건, 전체/실시간상담 필터)
  │     └── 검색결과 없음
  └── [탭: 후기] 후기 검색 (S268~S278)
        ├── 검색창 (상담사명 또는 후기내용)
        ├── 최근검색어 (전체삭제, 개별삭제)
        ├── 상담분야/상담스타일 접기/펼치기
        ├── 자동완성 드롭다운
        ├── 검색결과 (총 N건, 최근작성순)
        ├── 필터 (전체/상담분야/상담스타일)
        │     ├── 전체: 전화상담/채팅상담
        │     ├── 상담분야 목록
        │     └── 상담스타일 목록
        └── 검색결과 없음
```

### 핵심 특징

- **단일 페이지 2탭 구조**: 상담사/후기 탭 전환으로 검색 대상 변경 (라우트 변경 없음)
- **통합 검색 UI**: 두 탭 모두 동일한 검색창 + 최근검색어 + 분야/스타일 필터 구조 공유
- **자동완성**: 입력 중 실시간 자동완성 드롭다운 표시
- **최근검색어 관리**: 로컬 스토리지 기반, 개별/전체 삭제

## 2. 라우트 구조

| 라우트 | page.js 위치 | 동적 파라미터 | 인증 필요 | 슬라이드 |
|--------|-------------|-------------|---------|---------|
| `/[locale]/search` | `app/[locale]/search/page.js` | locale | 아니오 | S259~S278 |

### 라우트 상세

- 단일 라우트, 탭 전환은 클라이언트 상태로 관리 (URL 쿼리 파라미터 `?tab=counselor` / `?tab=review` 선택적)
- 비로그인 사용자도 검색 가능
- Header 검색 아이콘에서 진입 (전화상담/채팅상담/카테고리 등 다수 도메인에서 연결)

## 3. 페이지 정의

### 3-1. 검색 메인 — 상담사 탭 (슬라이드 S260~S267)

- **라우트**: `/[locale]/search` (기본 탭)
- **Server/Client 분리**: `page.js`(Server) → `SearchMain.js`(Client)
- **UI 섹션 — 초기 상태 (검색 전)** (상→하 순서):
  1. **검색 상단 바**: 뒤로가기 + 검색 input + 취소 버튼
  2. **탭 메뉴**: 상담사(기본 활성) / 후기 2탭
  3. **최근 검색어 영역**:
     - "최근검색어" 레이블 + "전체삭제" 버튼
     - 최근 검색어 칩 리스트 (가로 스크롤 또는 세로 나열)
     - 각 칩에 X(개별삭제) 버튼
     - 검색어 없을 때: "최근 검색어가 없습니다" 빈 상태
  4. **자주상담한 상담사 리스트** (로그인 시):
     - "자주 상담한 상담사" 레이블
     - 상담사 카드 리스트 (프로필 이미지 + 닉네임 + 카테고리)
     - 비로그인 시: 미표시
  5. **상담분야 섹션** (접기/펼치기):
     - "상담분야" 레이블 + 토글 아이콘
     - 펼침 시: 연애운, 짝사랑, 궁합, 결혼, 이별, 재회, 삼각관계, 불륜, 직장/사업, 학업/진로, 대인관계, 가족관계, 금전운, 건강운, 꿈해몽, 기타 등 태그 칩
     - 클릭 시 해당 분야로 검색 실행
  6. **상담스타일 섹션** (접기/펼치기):
     - "상담스타일" 레이블 + 토글 아이콘
     - 펼침 시: 정확해요, 편안해요, 친절해요, 공감해요, 응원해요, 솔직해요, 따뜻해요, 재미있어요, 빨라요, 상세해요, 신비로워요, 전문적이에요 등 태그 칩
     - 클릭 시 해당 스타일로 검색 실행

- **UI 섹션 — 자동완성 (입력 중)**:
  - 검색 input 입력 시 → 자동완성 드롭다운 오버레이
  - 매칭되는 상담사명/고유번호 리스트 표시
  - 항목 클릭 → 해당 상담사로 즉시 검색 실행

- **UI 섹션 — 검색 결과**:
  1. **검색 결과 헤더**: "총 N건" 표시
  2. **필터 칩**: 전체 / 실시간상담 (상담 가능 상담사만 필터)
  3. **상담사 카드 리스트**: CounselorCard 리스트 (프로필, 닉네임, 카테고리, 코인, 상태)
  4. **검색 결과 없음**: "검색 결과가 없습니다" 빈 상태 + 이미지

- **상태 관리**:
  - 로컬 상태: 활성 탭 (counselor/review), 검색 키워드, 자동완성 리스트, 검색 결과, 분야/스타일 펼침 상태, 최근검색어 배열
  - 로컬 스토리지: 최근검색어 (최대 20개, FIFO)
  - Zustand 스토어: 사용하지 않음

- **API 연동**:
  | 엔드포인트 | Method | Request Body | Response |
  |-----------|--------|-------------|----------|
  | `/api/search/counselor` | POST | `{ keyword, offset, limit, filter, locale }` | `{ response, items: CounselorCard[], total }` |
  | `/api/search/autocomplete` | POST | `{ keyword, type: 'counselor', locale }` | `{ suggestions: AutocompleteItem[] }` |
  | `/api/search/frequentCounselors` | POST | `{ locale }` | `{ items: CounselorCard[] }` |

- **사용자 인터랙션**:
  - 검색 input 입력 → debounce → 자동완성 API 호출 → 드롭다운 표시
  - Enter 키 또는 검색 버튼 → 검색 실행 → 결과 표시 + 최근검색어 저장
  - 자동완성 항목 클릭 → 즉시 검색 실행
  - 최근 검색어 칩 클릭 → 해당 키워드로 재검색
  - 최근 검색어 X 클릭 → 개별 삭제
  - "전체삭제" 클릭 → 전체 삭제 확인 → 삭제
  - 상담분야/상담스타일 토글 → 섹션 접기/펼치기
  - 분야/스타일 태그 칩 클릭 → 해당 조건으로 검색 실행
  - 자주상담한 상담사 클릭 → 상담사 프로필 이동
  - 검색 결과 카드 클릭 → 상담사 프로필 이동
  - 필터 전환 (전체/실시간상담) → 결과 재필터링
  - 뒤로가기 / 취소 → 이전 페이지 복귀

- **비즈니스 규칙**:
  - 최근검색어: 로컬 스토리지 저장, 최대 20개, 중복 제거 (기존 항목 최상단 이동)
  - 자동완성: 2글자 이상 입력 시 활성화, debounce 300ms
  - 자주상담한 상담사: 로그인 필수, 최근 상담 이력 기반

- **i18n 네임스페이스**: `search`
  - 주요 키: `counselorTab`, `reviewTab`, `searchPlaceholderCounselor`, `recentSearch`, `clearAll`, `frequentCounselors`, `counselingField`, `counselingStyle`, `totalCount`, `allFilter`, `liveFilter`, `noResult`, `noRecentSearch`

- **외부 의존성**: 없음

### 3-2. 검색 메인 — 후기 탭 (슬라이드 S268~S278)

- **라우트**: `/[locale]/search` (후기 탭 활성)
- **Server/Client 분리**: 동일 `SearchMain.js`(Client) 내 탭 분기
- **UI 섹션 — 초기 상태 (검색 전)** (상→하 순서):
  1. **검색 상단 바**: 뒤로가기 + 검색 input (placeholder: "상담사명 또는 후기내용") + 취소 버튼
  2. **탭 메뉴**: 상담사 / 후기(활성) 2탭
  3. **최근 검색어 영역**: 상담사 탭과 동일 구조 (단, 후기 검색어 별도 관리)
  4. **상담분야 섹션** (접기/펼치기): 상담사 탭과 동일 분야 목록
  5. **상담스타일 섹션** (접기/펼치기): 상담사 탭과 동일 스타일 목록

- **UI 섹션 — 자동완성 (입력 중)**:
  - 상담사명 또는 후기 내용 매칭 자동완성 드롭다운

- **UI 섹션 — 검색 결과**:
  1. **검색 결과 헤더**: "총 N건" + 정렬 기준 "최근작성순"
  2. **필터 탭**: 전체 / 상담분야 / 상담스타일 3탭
     - **전체 필터**: 전체 / 전화상담 / 채팅상담
     - **상담분야 필터**: 전체 + 분야 목록 (연애운, 짝사랑, 궁합 ...)
     - **상담스타일 필터**: 전체 + 스타일 목록 (정확해요, 편안해요 ...)
  3. **후기 카드 리스트**: ReviewCard 리스트 (상담사 정보, 후기 내용, 별점, 작성일)
  4. **검색 결과 없음**: "검색 결과가 없습니다" 빈 상태

- **후기 카드 구성**:
  | 필드 | 설명 |
  |------|------|
  | 상담사 프로필 | 이미지 + 닉네임 |
  | 상담 유형 | 전화상담/채팅상담 구분 뱃지 |
  | 별점 | ★ 1~5점 표시 |
  | 후기 내용 | 텍스트 (길면 말줄임) |
  | 작성일 | YYYY.MM.DD 형식 |
  | 상담분야 태그 | 해당 상담의 분야 태그 |
  | 상담스타일 태그 | 해당 상담의 스타일 태그 |

- **필터 시스템 상세 (S273~S278)**:

  #### 3-2-1. 전체 필터 (S274)
  상담 유형별 필터링. 단일 선택 (라디오).

  | 옵션 | 설명 |
  |------|------|
  | 전체 (기본) | 전화+채팅 후기 모두 표시 |
  | 전화상담 | 전화상담 후기만 표시 |
  | 채팅상담 | 채팅상담 후기만 표시 |

  #### 3-2-2. 상담분야 필터 (S275~S276)
  분야별 필터링. 단일 선택.

  | 옵션 | 설명 |
  |------|------|
  | 전체 (기본) | 모든 분야 |
  | 연애운 | 연애운 분야 후기만 |
  | 짝사랑 | 짝사랑 분야 후기만 |
  | 궁합 | 궁합 분야 후기만 |
  | 결혼 | 결혼 분야 후기만 |
  | ... (기타 분야) | 각 분야별 |

  #### 3-2-3. 상담스타일 필터 (S277~S278)
  스타일별 필터링. 단일 선택.

  | 옵션 | 설명 |
  |------|------|
  | 전체 (기본) | 모든 스타일 |
  | 정확해요 | 정확한 스타일 후기만 |
  | 편안해요 | 편안한 스타일 후기만 |
  | ... (기타 스타일) | 각 스타일별 |

- **상태 관리**:
  - 로컬 상태: 검색 키워드, 자동완성 리스트, 검색 결과, 활성 필터 탭 (전체/분야/스타일), 선택된 필터 값, 분야/스타일 펼침 상태, 최근검색어 배열
  - 로컬 스토리지: 최근검색어 (후기 탭 전용, 상담사 탭과 별도)

- **API 연동**:
  | 엔드포인트 | Method | Request Body | Response |
  |-----------|--------|-------------|----------|
  | `/api/search/review` | POST | `{ keyword, offset, limit, type, field, style, sort, locale }` | `{ response, items: ReviewCard[], total }` |
  | `/api/search/autocomplete` | POST | `{ keyword, type: 'review', locale }` | `{ suggestions: AutocompleteItem[] }` |

- **사용자 인터랙션**:
  - 검색 input 입력 → debounce → 자동완성 API 호출
  - Enter / 검색 버튼 → 검색 실행 → 결과 표시
  - 필터 탭 전환 (전체/상담분야/상담스타일) → 필터 옵션 표시 변경
  - 필터 옵션 선택 → 결과 재필터링
  - 후기 카드 클릭 → 후기 상세 또는 상담사 프로필 이동
  - 무한 스크롤: offset 증분 fetch

- **비즈니스 규칙**:
  - 기본 정렬: 최근작성순 (작성일 내림차순)
  - 필터 3종 (전체/분야/스타일)은 교차 적용: type AND field AND style
  - 후기 내용 말줄임: 2줄 초과 시 "..." 처리

- **i18n 네임스페이스**: `search`
  - 추가 키: `searchPlaceholderReview`, `sortRecent`, `filterAll`, `filterField`, `filterStyle`, `filterPhone`, `filterChat`, 분야/스타일 각 항목 키

- **외부 의존성**: 없음

## 5. 크로스 도메인 의존성

| 방향 | 대상 도메인 | 연결 내용 |
|------|-----------|----------|
| 피의존 | `call` (전화상담) | Header 검색 아이콘 → 검색 페이지 진입 |
