# 크로스 도메인 공유 컴포넌트 (초안)

> 여러 도메인에서 반복 사용되는 UI 패턴을 식별하여 공유 컴포넌트 후보를 기록한다.
> Phase E(최종화) 단계에서 실제 구현 가능한 컴포넌트로 확정한다.

## 1. 이미 구현된 공유 컴포넌트

| 컴포넌트 | 경로 | 사용 도메인 | 비고 |
|---------|------|-----------|------|
| Header | `components/Header.js` | 전체 | 루트 레이아웃 |
| Footer (GNB) | `components/Footer.js` | 전체 | 하단 고정 네비게이션 |
| ListEmpty | `components/ListEmpty.js` | 리스트 페이지들 | 빈 상태 표시 |
| PageNavBar | `app/[locale]/_components/PageNavBar.js` | 하위 페이지들 | Phase 3.5에서 리팩토링 완료 |

## 2. 기획서에서 식별된 공유 컴포넌트 후보

### 2-1. 상담사 카드 (CounselorCard)
- **사용 도메인**: 전화상담, 채팅상담, 검색, 단골, 카테고리 리스트
- **구성**: 프로필 이미지 + 닉네임(가타카나) + 카테고리 + 스타일 태그 + 후기 통계 + 코인/30초 + 상담 상태(가능/중/부재)
- **변형**: 그리드 뷰 / 리스트 뷰

### 2-2. 필터 바텀시트 (FilterBottomSheet)
- **사용 도메인**: 전화상담 카테고리, 채팅상담 카테고리, 검색
- **구성**: 정렬 / 스타일(최대3개) / 분야(최대3개) / 상담코인 / 상담가능만보기
- **동작**: 3개 초과 선택 시 경고 알럿

### 2-3. 후기 카드 (ReviewCard)
- **사용 도메인**: 전체후기, 프로필>후기, 검색>후기
- **구성**: 닉네임 + 별점(★) + 후기 텍스트 + 날짜 + 신고 버튼
- **변형**: 전체/베스트/손글씨 탭, 상담스타일/상담분야 차트

### 2-4. 신고 모달 (ReportModal)
- **사용 도메인**: 전체후기, 프로필>후기
- **구성**: 회원신고 / 후기신고 선택 → 사유 입력 → 제출

### 2-5. 상담사 프로필 탭 (ProfileTabs)
- **사용 도메인**: 전화상담 프로필, 채팅상담 프로필
- **구성**: 판매상품 / 상세정보 / 후기 / 1:1문의 / 포스팅 탭
- **차이점**: 전화상담은 `[번호]` 표시, 채팅상담은 번호 없음

### 2-6. 포스팅 카드 (PostingCard)
- **사용 도메인**: 카테고리>상담사포스팅, 프로필>포스팅
- **구성**: 제목 + 이미지 + 조회수 + 추천수 + 상담사 정보 + 날짜

### 2-7. 상담 하단 네비게이션 (ConsultationBottomNav)
- **사용 도메인**: 전화상담 프로필, 채팅상담 프로필
- **구성**: 단골 버튼 + 상담하기 버튼
- **상태별**: 상담가능(활성) / 상담중(비활성+알림신청) / 부재중(비활성+알림신청)

### 2-8. 기간 필터 (PeriodFilter)
- **사용 도메인**: 회원 마이메뉴(상담내역, 코인내역, 결제내역), 상담사 마이메뉴(상담내역)
- **구성**: 1개월 / 3개월 / 6개월 탭

### 2-9. 알림 내역 탭 (NotificationTabs)
- **사용 도메인**: 회원 마이메뉴>알림내역
- **구성**: 전체 / 공지사항 / 활동알림 / 이벤트

### 2-10. 공유 바텀시트 (ShareBottomSheet)
- **사용 도메인**: 프로필>상세정보>공유, 포스팅>공유
- **구성**: 공유 옵션 목록 (카카오톡, LINE, 링크복사 등)

## 3. 상태 관리 (Zustand) 공유 스토어 후보

| 스토어 | 사용 도메인 | 상태 |
|--------|-----------|------|
| `useCateStore` | 메인, 카테고리 리스트 | ✅ 이미 구현 |
| `useAuthStore` (추정) | 로그인, 회원가입, 마이메뉴 | 로그인 상태, 사용자 정보 |
| `useFilterStore` (추정) | 전화상담, 채팅상담, 검색 | 필터 선택 상태 |
| `useCoinStore` (추정) | 코인충전, 상담하기, 마이메뉴 | 보유코인 |
| `useChatStore` (추정) | 채팅상담 | 채팅방 상태, 메시지 |
