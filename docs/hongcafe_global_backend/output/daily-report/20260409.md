## 5. 특이사항

- **CSRF 정책 재검토**: CLAUDE.md에 "CI4 Session-Based CSRF 필수"로 명시되어 있었으나, stateless JWT 아키텍처와 불일치 확인. OWASP 근거 기반으로 **Signed Double Submit Cookie (HMAC-SHA256)** 방식으로 정책 변경 예정.
