# 업적 KPI 표 양식 (70%)

컬럼: 영역 | 세부항목 | 평가방식 | 산정 기준 | 가중치 | 점수 | 환산 | 등급 | 종합의견

- **평가방식**: 전 영역 `정량평가` 표기 (2026-07-02 사용자 지시).
- **산정 기준 형식 (3요소)**: `총점(110) = 일정준수(50) + 기능점수(60)` · `달성률: n/m = %` · `일정 연체: N일`. AWS 인프라만 총점(120) = 50 + 70.
- **달성률 분모** = 영역별 실측으로 조절: 간트 직접(API) / IEEE 세트 완결(설계) / Critical 조치율(보안) / 계획 대비 완료(인프라) / 전수 커버리지(QA) / e2e·계측 통과율(자동화) / 핵심 트랙 완료(DB).

기본 7영역·가중치 (합 70% — 분기 산출 분포가 크게 바뀌면 조절하되 사유 명기):

| 영역 | 세부항목 | 가중치 |
|---|---|---|
| 데이터베이스 | DB 설계/운영 (스키마·쿼리·복제) | 8% |
| 개발 | 분석/설계 (요구사항·아키텍처) | 12% |
| 개발 | 보안 (취약점·인증체계·컴플라이언스) | 10% |
| 개발 | API 개발 (RESTful 설계/구현/테스트) | 16% |
| 서버관리 | AWS 인프라 관리 (구축·비용·R&D) | 12% |
| 품질관리 | QA/검증·출시 준비 | 6% |
| 개발환경 | 개발 프로세스 자동화 | 6% |

- **소계 행**: 점수 = Σ환산 ÷ 70% (표시 반올림 값 합산 기준, 3월 관례), 등급 경계 90 = A / 89 = B.
- **종합의견 톤**: 구체 성과 + 차별점 ("~한 점이 우수/차별적"), 명사형 종결. 아키텍처 수준·선제성·리스크 통제를 근거로 명시.
- **2026 Q2 기준선** (직전 대비 표기용): 87 / 90 / 88 / 90 / 90 / 89 / 86 → 소계 89.0 / 62.3 / B. (3월 5영역: 88.0 / 80.7 / 80.0 / 80.0 / 91.2 → 84.3 / 59.0 / B)
