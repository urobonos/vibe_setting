# 인사 제출본 정비 규칙

인사결정권자 열람 전제. 산정본과 점수·등급 동일, 서술만 정비.

**금지 (내부 용어):** Claude · AI · 에이전트 · 하니스 · hook · 스킬/슬래시명 · 커밋 해시 · 빌드/파이프라인 번호 · 내부 문서 경로 · 분석 도구명 · 세션.

**치환 예:** "간트 실측" → "WBS 실측" / "prd 배포 커밋 60건" → "운영 배포 60여 회" / "worktree 안전장치" → "위험 작업 차단 체계" / "cold Agent 병렬 실측" → "코드 저장소 실측".

**서술:**
- 자기 유보 문장("본인 결함 사후 수정" 류) 배제 — 등급 근거는 성과 서술로 내재.
- 명사형 종결 (~함 / ~우수 / ~차별적). 3월 시트 톤 준용.
- 기술 약어는 일반어 병기: BOLA(권한 우회) · IDOR(객체 참조) · IaC(코드형 인프라).

**수치:** 성과 수치(달성률·테스트 수·배포 횟수·비용 절감)만 유지, 측정 도구·방법의 내부명 제거.

**전체 종합의견:** 산문 2~3문장, 수치 최소(합계 점수 정도), 세부항목 의견과 중복(리바이벌) 금지, 평가성 사족·전망 서술 금지 — 읽기 좋은 사실 서술.
