# 평가 공통 원칙 (역량·업적 공용 SSOT)

1. **기준선 SSOT** = 메모리 `project_perf-eval-supervisor.md` — 실행 전 정독. 직전 확정본·사용자 지시(상한 등)가 본 플러그인 기본값보다 우선.
2. **관대화 경계**: git·간트·테스트 수치로 증빙 가능한 항목만 상향 (5월 초안 89.9 → 확정 88.5 하향 전례). 증빙 불가 축(근태·태도)은 전월 유지가 기본.
3. **등급 경계**: 90 = A, 89 = B. **역량 소계 상한 = 89.9** (소계 A 진입 금지, 2026-07-02 사용자 지시 — 해제는 사용자 명시로만).
4. **산정 골격**: 항목 총점(110~120) = 일정준수(50) + 기능점수(60~70) · 점수 100 환산 · 환산 = 점수 × 가중치 · 업적 70% + 역량 30% = 합계 100% · **달성률 100% ≠ 100점** (기능점수 재량).
5. **산출물**: `~/.claude/docs/claude-harness/output/report/{yyyy-mm-dd}-{대상}-eval/` 1폴더 1문서, `## 참조 출처` + 작성 정보 박스 필수.
6. **마감**: 결과를 메모리 기준선에 **"제안"** 으로 기록 (확정은 사용자 시트 반영 후 별도 갱신). 제안 vs 확정 구분 명기.

## 수집 실패 대비 (공용)

- agent 빈손 반환(세션 한도 등) 시 대상 축소(핵심 파일 3종) 재시도 1회.
- 간트 기한 컬럼 부재 → "연체 0일" = "기한 초과 기록 없음 + 잔여 전건 승인 보류" 의미로 명기.
- 월별 단독 수치 부재 구간은 한계 고지에 기록 (소급 추정 금지). 증빙은 세션 기록 한정 = 실제 업무량의 하한임을 고지.
