# Config Audit Rubric (SSOT)

> 단일 진실 소스. SKILL.md, audit-config.md 모두 이 파일을 참조한다.
> 수정 시 이 파일만 수정. 근거: best-practices.md (references/)

## 카테고리별 체크리스트

### 1. CLAUDE.md (글로벌) — 가중치 20%

| # | 항목 | 판정 기준 (Y/N) |
|---|------|----------------|
| 1-1 | 줄 수 적정성 | 150줄 이하인가 (경험적 기준 — 공식 수치 없음. 초과 시 분리 필요 여부 확인) |
| 1-2 | 부정어 비율 | "Do not", "Never", "금지" 등 부정어 비율이 전체 규칙의 15% 미만인가 (경험적 임계치 — Anthropic은 "리프레이밍 권장"만 명시, 수치 기준 없음) |
| 1-3 | 신호 대 잡음 | "Claude가 지침 없이도 맞게 할 내용"이 포함되어 있지 않은가 |
| 1-4 | 리프레이밍 | 부정어가 "Prefer X over Y" 형식으로 리프레이밍 가능한 항목이 없는가 |
| 1-5 | Hooks 위임 | 100% 강제 필요 규칙이 hooks가 아닌 CLAUDE.md에만 존재하지 않는가 |

### 2. CLAUDE.md (프로젝트) — 가중치 10%

| # | 항목 | 판정 기준 (Y/N) |
|---|------|----------------|
| 2-1 | 프로젝트 특화도 | 프로젝트에만 해당하는 규칙으로 구성되었는가 |
| 2-2 | 글로벌 중복률 | 글로벌 CLAUDE.md와 중복되는 규칙이 20% 미만인가 |
| 2-3 | 아키텍처 명시 | 프로젝트 고유 아키텍처, 기술 스택, 컨벤션이 명시되었는가 |

### 3. Settings 구조 — 가중치 15%

| # | 항목 | 판정 기준 (Y/N) |
|---|------|----------------|
| 3-1 | 계층 분리 | global settings.json과 project settings.local.json의 역할이 분리되었는가 |
| 3-2 | 권한 중복 | global과 local 간 permissions 중복률이 30% 미만인가 |
| 3-3 | 최소 권한 | allowedTools에 불필요한 도구가 포함되지 않았는가 |
| 3-4 | 환경 일관성 | settings에 정의된 환경변수/경로가 실제 존재하는가 |

### 4. Hooks 품질 — 가중치 15%

| # | 항목 | 판정 기준 (Y/N) |
|---|------|----------------|
| 4-1 | 이벤트 커버리지 | PreToolCall, PostToolCall, Notification 등 주요 이벤트가 활용되고 있는가 |
| 4-2 | 타입 분류 적정 | 결정적 검증은 command hook, LLM 판단은 prompt hook으로 올바르게 분류되었는가 |
| 4-3 | Timeout 적정성 | 각 hook의 timeout이 작업 복잡도에 맞게 설정되었는가 (기본 10s 기준) |
| 4-4 | 에러 핸들링 | hook 실패 시 fallback 또는 에러 메시지가 정의되었는가 |

### 5. Commands 구조 — 가중치 10%

| # | 항목 | 판정 기준 (Y/N) |
|---|------|----------------|
| 5-1 | 설명 명확성 | 커맨드 첫 줄에 목적과 사용법이 명시되었는가 |
| 5-2 | $ARGUMENTS 활용 | 인자 파싱 로직이 명확하고, 미입력 시 fallback이 있는가 |

| 5-4 | Git 체크인 | 공유 가능한 커맨드가 git으로 관리되고 있는가 |

| 8-4 | 네이밍 일관성 | 커맨드/스킬/에이전트의 네이밍 규칙이 통일되어 있는가 |

## 점수 산출

- **카테고리 점수**: (Y 개수 / 전체 항목 수) x 100
- **총점**: SUM(카테고리 점수 x 가중치)
  - 예: 카테고리1 점수 80 x 0.20 + 카테고리2 점수 100 x 0.10 + ...

## Gate 판정

- **PASS**: 총점 >= 80
- **REVIEW**: 총점 60 ~ 79 -- 이슈 목록과 개선 제안 필수 제시
- **FAIL**: 총점 < 60 -- 전면 재설정 권고. 카테고리별 개선 로드맵 제시
