# Part B: 공통 보안 체크리스트

**적용 시점:** 모든 코드 변경, 의존성 추가/업데이트, 배포 전 최종 점검 시

## B1. 인젝션 방어 (CWE-79, 89, 78)

- [ ] XSS 출력 시 `esc()` 적용되어 있는가
- [ ] OS 명령 실행 함수(exec, system, passthru)에 사용자 입력이 포함되지 않는가
- [ ] `unserialize()`에 사용자 입력이 전달되지 않는가
- [ ] `eval()`, `extract()`, `assert(문자열)` 사용이 없는가
- [ ] LDAP 쿼리에 사용자 입력이 직접 삽입되지 않는가 (ASVS 1.2.6)
- [ ] XML 파서에 외부 엔티티 해석(XXE)이 비활성화되어 있는가 (ASVS 1.5.1)
- [ ] 정규표현식에 사용자 입력 사용 시 메타문자 이스케이프(ReDoS 방지)가 적용되는가 (ASVS 1.2.9)
- [ ] CSV/스프레드시트 출력 시 수식 인젝션(=, +, -, @)이 방지되는가 (ASVS 1.2.10)
- [ ] 사용자 제공 URL에서 `javascript:`, `data:` 프로토콜이 차단되는가 (ASVS 1.2.2)
- [ ] SMTP/IMAP 인젝션 방지를 위해 메일 입력이 새니타이즈되는가 (ASVS 1.3.11)
- [ ] 템플릿 인젝션 방지를 위해 사용자 입력으로 템플릿을 동적 구성하지 않는가 (ASVS 1.3.7)

## B2. 인증 강화 (CWE-287, 306, 798)

- [ ] 비밀번호가 bcrypt/argon2로 해싱되는가
- [ ] 세션 토큰에 만료 시간이 설정되어 있는가
- [ ] 기본 계정(root, admin, sa)이 존재하지 않거나 비활성화되어 있는가 (CWE-798)
- [ ] 비밀번호가 최소 8자 이상이며, 취약 비밀번호 목록과 대조되는가 (ASVS 6.2.1)
- [ ] 크리덴셜 스터핑/브루트포스 방어가 적용되는가 (CWE-306)
- [ ] 인증 실패 응답이 유효 사용자 존재 여부를 노출하지 않는가 (CWE-287)
- [ ] 로그인 성공 시 세션 토큰이 재생성되는가 (ASVS 7.2.4)
- [ ] 비밀번호 변경 시 현재 비밀번호 확인이 필수인가 (ASVS 6.2.3)
- [ ] 초기 비밀번호/활성화 코드가 짧은 유효기간을 가지는가 (ASVS 6.4.1)

## B3. 세션 관리 (ASVS V7)

- [ ] 세션 토큰이 최소 128비트 엔트로피의 CSPRNG로 생성되는가 (ASVS 7.2.3)
- [ ] 로그아웃/만료 시 세션이 완전히 무효화되어 재사용 불가능한가 (ASVS 7.4.1)
- [ ] 계정 비활성화/삭제 시 모든 활성 세션이 종료되는가 (ASVS 7.4.2)
- [ ] 민감 계정 속성 변경 전 재인증이 요구되는가 (ASVS 7.5.1)

## B4. 접근 제어 (CWE-862, ASVS V8)

- [ ] 수직/수평 권한 상승이 차단되어 있는가
- [ ] 모든 API에서 리소스별 접근 권한(IDOR/BOLA)이 검증되는가 (CWE-862)
- [ ] 필드 수준 접근 제어가 적용되어 민감 필드가 보호되는가 (ASVS 8.2.3)
- [ ] 멀티테넌트 환경에서 테넌트 간 데이터 격리가 보장되는가 (ASVS 8.4.1)

## B5. 입력 검증 (ASVS V5)

- [ ] 모든 사용자 입력에 서버 측 검증이 존재하는가
- [ ] 상태 변경 요청(POST/PUT/DELETE)에 CSRF 보호가 적용되는가 (CWE-352)
- [ ] 파일 경로 구성 시 사용자 입력 미포함(Path Traversal 방지)인가 (CWE-22)
- [ ] 파일 업로드 시 매직 바이트 + 확장자 검증이 수행되는가 (CWE-434)
- [ ] 압축 파일 해제 시 크기/파일 수 제한 및 Zip Slip 방지가 적용되는가 (ASVS 5.2.3)
- [ ] 사용자별 파일 업로드 용량/개수 쿼터가 적용되는가 (ASVS 5.2.4)
- [ ] SSRF 방지를 위해 외부 URL 요청 시 프로토콜/도메인 허용 목록이 적용되는가 (CWE-918)

## B6. API 보안 (ASVS V4, V13)

- [ ] Content-Type 헤더가 응답 본문과 일치하며 charset(UTF-8)이 명시되는가 (ASVS 4.1.1)
- [ ] 허용된 HTTP 메서드만 수락하고 미사용 메서드(TRACE 등)가 차단되는가 (ASVS 4.1.4)
- [ ] HTTP 요청 스머글링 방지를 위해 메시지 경계가 올바르게 처리되는가 (ASVS 4.2.1)
- [ ] 과도하게 긴 URI/헤더에 대한 크기 제한이 적용되는가 (ASVS 4.2.5)

## B7. 암호화 (ASVS V11)

- [ ] 검증된 암호화 라이브러리만 사용되며, 자체 구현 암호화가 없는가 (ASVS 11.2.1)
- [ ] MD5, SHA1 등 취약한 해시 함수가 사용되지 않는가 (ASVS 11.4.1)
- [ ] 난수 생성이 CSPRNG를 통해 최소 128비트 엔트로피로 수행되는가 (ASVS 11.5.1)

## B8. 데이터 보호 (ASVS V14)

- [ ] 민감 데이터가 URL/쿼리스트링이 아닌 HTTP 본문/헤더로만 전송되는가 (ASVS 14.2.1)
- [ ] 민감 데이터에 대한 보존 기간 정책과 자동 삭제가 적용되는가 (ASVS 14.2.7)
- [ ] API 응답에 불필요한 민감 정보가 마스킹되는가 (ASVS 14.2.6)

## B9. 에러 처리 및 로깅 (ASVS V16)

- [ ] 에러 응답에 스택 트레이스/내부 정보가 노출되지 않는가
- [ ] 인증 시도(성공/실패)가 메타데이터와 함께 기록되는가 (ASVS 16.3.1)
- [ ] 인가 실패 시도가 로그에 기록되는가 (ASVS 16.3.2)
- [ ] 로그에 민감 데이터(비밀번호, 토큰)가 기록되지 않는가 (ASVS 16.2.5)
- [ ] 로그 인젝션 방지를 위해 인코딩이 적용되는가 (ASVS 16.4.1)
- [ ] 외부 리소스 장애 시 Circuit Breaker 등 안전한 실패 처리가 적용되는가 (ASVS 16.5.2)

## B10. 의존성/SCA (ASVS V13)

- [ ] `composer audit` 결과 Critical CVE가 없는가
- [ ] 소스 코드 메타데이터(.git, .svn)가 프로덕션에서 접근 불가능한가 (ASVS 13.4.1)
- [ ] 프로덕션에서 디버그 모드가 비활성화되어 있는가 (ASVS 13.4.2)
- [ ] 시크릿이 시크릿 관리 솔루션을 통해 관리되는가 (ASVS 13.3.1)
- [ ] 백엔드 서비스 계정에 최소 권한 원칙이 적용되는가 (ASVS 13.2.2)

## B11. 비즈니스 로직 보안

- [ ] 결제/재고 등 민감 로직에 동시성 제어가 적용되어 있는가
- [ ] 주문 금액 조작 방지(서버 DB 가격 vs 클라이언트 가격 비교)가 적용되는가
- [ ] 쿠폰/할인 중복 적용이 방지되는가
- [ ] 결제 상태 전이 무결성(상태 머신 패턴)이 적용되는가
- [ ] 무제한 리소스 소비(CPU, 메모리, API 호출) 방지 제한이 설정되어 있는가 (CWE-400)
- [ ] 비즈니스 로직 흐름이 예상된 단계를 따르는가 (ASVS 2.3.1)
