다음 세션 시작 직후 호출하는 잔존 작업 로드 슬래시. `/작업저장` 분기 B (Status: Partial + `## 잔여 작업` 섹션) 로 working/ 에 보관된 작업을 다시 컨텍스트로 끌어온다.

## 동작 3단계

| 단계 | 동작 | 결과 |
|------|------|------|
| ① 잔존 작업 스캔 + 빈 폴더 정리 | `~/.claude/docs/working/YYYYMMDD/` 전체 스캔 → `Status: Partial` 마커 + `## 잔여 작업` 섹션 동시 보유 파일 추출. **금일(`date +%Y%m%d`) 이전 폴더 중 `*.md` 파일 0건이면 해당 폴더 자동 삭제** (working/ → tasks/ 이동 후 남은 빈 껍데기 정리). | 잔존 목록 + 빈 폴더 0건 |
| ② 인자 분기 처리 | 인자 없음 = 목록 표시 / `{작업명}` = 본문 출력 / `latest` = 가장 최근 1건 자동 선택 | 본문 또는 목록 |
| ③ 재진입 안내 | 잔여 항목 미체크 박스 추출 + `/자동진행 {요약}` 제안 | 다음 액션 결정 |

## 호출 방식

| 인자 | 동작 |
|------|------|
| 인자 없음 (`/작업로드`) | 잔존 작업 목록 표시 (날짜·product·작업명·잔여 개수) |
| `{작업명}` (`/작업로드 auth-refactor`) | 파일명 매칭 → 해당 작업 본문 + 잔여 항목 표시 |
| `latest` (`/작업로드 latest`) | 가장 최근 잔존 작업 1건 자동 선택 → 본문 + 잔여 항목 표시 |

## ① 잔존 작업 스캔 + 빈 폴더 정리

**REGISTRY 우선 조회 (2026-05-15 신설):** `~/.claude/docs/working/REGISTRY.md` 마크다운 표 우선 조회 → 본 세션 sid 와 비교해 `[active by other]` / `[paused]` / `[orphan]` 3분류. 그 다음 working/ 직접 grep 으로 보강.

```bash
# 0) REGISTRY 우선 — 다른 세션 점유 + paused 본 세션 잔존 식별
source ~/.claude/hooks/lib/registry-utils.sh
registry_list_active                 # status=active 전체 (본인 sid 아니면 다른 세션 점유)

# 1) 스캔 대상: ~/.claude/docs/working/YYYYMMDD/*.md
# 조건: Status: Partial (시작 라인) AND ## 잔여 작업 (h2 섹션 존재)
grep -lE '^Status:\s*Partial' ~/.claude/docs/working/*/*.md 2>/dev/null \
  | xargs -I{} grep -lE '^## 잔여 작업' {} 2>/dev/null

# 2) 금일 이전 빈 폴더 자동 삭제 (working/ → tasks/ 이동 후 남은 빈 껍데기 정리)
TODAY=$(date +%Y%m%d)
for dir in ~/.claude/docs/working/*/; do
  base=$(basename "$dir")
  # 폴더명이 YYYYMMDD 형식인지 검사
  echo "$base" | grep -qE '^[0-9]{8}$' || continue
  # 금일 이후 (포함) 면 보호 — 진행 중일 수 있음
  [ "$base" -ge "$TODAY" ] && continue
  # *.md 파일 0건이면 폴더 삭제 (rmdir 는 빈 폴더만 삭제 — 비어 있지 않으면 자동 실패)
  if [ -z "$(find "$dir" -maxdepth 1 -name '*.md' -print -quit 2>/dev/null)" ]; then
    rmdir "$dir" 2>/dev/null && echo "[CLEAN] removed empty working folder: $base"
  fi
done
```

각 파일에 대해 메타 추출:

| 필드 | 추출 방법 |
|------|---------|
| 날짜 | 파일명 `{yyyy-mm-dd}-` prefix |
| product | 파일명 `{yyyy-mm-dd}-{product}-...` 두 번째 토큰 |
| 작업명 | 파일명 나머지 (`.md` 제외) |
| 잔여 개수 | `## 잔여 작업` 섹션 안 `- [ ]` 카운트 |
| 마지막 수정 | `stat -c %y` |

## ② 인자 분기 처리

### 인자 없음 — 목록 표시

```
[Claude] 잔존 작업 N건 발견:

  1. 2026-05-13 / claude-harness / hook-cleanup
     ├─ 잔여 3건
     ├─ 마지막 수정: 2026-05-13 18:42
     └─ 진입: /작업로드 hook-cleanup

  2. 2026-05-14 / hongcafe_global_backend / auth-refactor
     ├─ 잔여 1건
     ├─ 마지막 수정: 2026-05-14 09:15
     └─ 진입: /작업로드 auth-refactor

  가장 최근 자동 선택: /작업로드 latest
```

### `{작업명}` — 본문 출력

```bash
# 파일명 매칭
cat ~/.claude/docs/working/YYYYMMDD/{yyyy-mm-dd}-{product}-{작업명}.md
```

전체 본문 출력 후 `## 잔여 작업` 섹션 부각 + 재진입 제안.

### `latest` — 자동 선택

가장 최근 mtime 잔존 파일 1건 → `{작업명}` 분기와 동일하게 본문 출력 + 재진입 제안.

## ③ 재진입 안내

본문 표시 후 잔여 항목 요약:

```
[Claude] 본 작업 잔여 3건:
  - [ ] CI4 Routes 캐시 무효화 — Auth 모듈 변경 후 캐시 재빌드 필요
  - [ ] integration test 추가 — login 흐름 e2e 1건 누락
  - [ ] CHANGELOG 1줄 보강 — 2026-05-14 항목

  재진입 옵션:
  ① /자동진행 잔여 3건 일괄 처리                  ← 묶음 승인 모드 진입
  ② 개별 항목 직접 지시 (예: "Routes 캐시 무효화부터")
  ③ 분기 처리 (Critical 만 처리 후 보류)

  어느 옵션으로 진행하시겠습니까?
```

**§3 Checkpoint 우선 적용:** 재진입 후 작업 수행은 §3 Checkpoint 매칭 시 별도 승인 요구. 본 슬래시는 **로드 (read-only)** 만 담당, 실제 작업 실행은 후속 슬래시 또는 사용자 지시.

## §3 Checkpoint 우선 적용

- 본 슬래시 = **준 read-only** (Read / Glob / Grep / Bash 조회계 + **금일 이전 빈 폴더 `rmdir` 1종**). working/ 파일 자체 수정 없음.
- **빈 폴더 정리 예외 사유:** (1) `*.md` 파일 0건만 대상 → 데이터 손실 0, (2) `rmdir` 는 비어 있지 않은 폴더 자동 실패 → 안전 잠금, (3) 금일 폴더는 보호 (진행 중일 수 있음). §3 Checkpoint "비가역 작업" 매칭이지만 무해 정리로 한정 — 매 호출 사용자 승인 면제.
- 실제 작업 진행 = 사용자 선택 후 후속 슬래시 호출 (`/자동진행` 등) 또는 직접 지시.
- 잔존 작업 파일 자체 삭제·이동 = 본 슬래시 비대상 — `/작업저장` 또는 `/working-done` 영역.

## 호출 예

```
/작업로드                       ← 잔존 작업 목록 표시
/작업로드 latest                ← 가장 최근 1건 자동 선택 + 본문 출력
/작업로드 auth-refactor         ← 특정 작업 본문 + 잔여 항목 표시
```

세션 재개 흐름 예시:

```
[사용자] /작업로드
   ↓
[Claude] ① 잔존 작업 스캔 → 2건 발견:
           1. 2026-05-13 / claude-harness / hook-cleanup    (잔여 3건)
           2. 2026-05-14 / hongcafe_global_backend / auth-refactor (잔여 1건)
        ② 목록 표시 + latest 자동 선택 옵션 안내
   ↓
[사용자] /작업로드 latest
   ↓
[Claude] ② auth-refactor 본문 출력 + 잔여 1건 부각:
           - [ ] integration test 추가 — login 흐름 e2e 1건 누락
        ③ 재진입 안내:
           ① /자동진행 integration test 추가
           ② 개별 항목 직접 지시
   ↓
[사용자] /자동진행 integration test 추가
   ↓
[Claude] (자동진행 모드 진입 → 작업 수행 → /작업저장 으로 마무리)
```
