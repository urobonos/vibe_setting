## 인자

- `$ARGUMENTS` = (선택) 작업명 kebab-case. 생략 시 가장 최근 working/ 파일 자동 식별.

| 단계 | 동작 | 결과 |
|------|------|------|
| ① 검토 대상 식별 | working/ §분석 의 권고 항목 중 라이브러리/아키텍처/API/보안/설계 결정 추출 | 대상 항목 N개 |
| ② docset-ref 스킬 호출 | 각 항목에 대해 Dash docset (php-net / claude-code / owasp-top10 / rfc-7231 등) SQLite 인덱스 조회 + HTML 원문 추출 | 공식 근거 N건 |
| ③ § 타당성 검토 표 채움 | `[Source: {name} §{id}]` 형식 인용 ≥ 1건 추가 | 표 행 ≥ 1 |

## 직병렬 실행 지침

**원칙:** 할당된 하위 태스크는 의존성을 먼저 판단 → 독립 태스크는 단일 응답 내 병렬(multi tool_use / Agent spawn), 의존 태스크는 직렬. 동일 파일 mutation·순서 의존 시 직렬 fallback (race 방지). 강제 병렬 modifier = `/병렬`.

| 태스크 | 직렬·병렬 | 방법 |
|--------|----------|-----|
| ② docset-ref N개 항목 조회 | **병렬 가능** | 검토 대상 N개 항목을 단일 응답 multi tool_use 로 docset-ref 동시 조회 |
| ① → ② → ③ 순서 | **직렬** | 대상 식별 후 조회, 조회 결과로 표 작성 (이전 단계 출력에 의존) |
