세션 종료 직전 호출하는 통합 저장 슬래시. `/working-done` (단순 이동) 과 `/자동진행` (실행 모드 진입) 의 중간 — **세션 마감 저장** 역할. 짝 슬래시 = **`/작업로드`** (다음 세션 시작 시 잔존 작업 불러오기).

## 동작 3단계

| 단계 | 동작 | 결과 |
|------|------|------|
| ① worktree 정착 안내 | `git worktree list` 스캔 → `~/.claude/worktrees/` 존재 시 정착 명령 안내 | 사용자 직접 실행 (`! ` prefix) |
| ② working/ 문서 마무리 | working/ 스캔 → 각 파일 잔여 작업 판정 | Status 결정 (Done / Partial) |
| ③ 잔여 작업 기록 / 이동 | 잔여 0건 = `Status: Done` 부착 → working-lifecycle 자동 이동 / 잔여 ≥ 1 건 = `Status: Partial` + `## 잔여 작업` 섹션 추가 → working/ 유지 (다음 세션 `/작업로드` 진입점) | 분기 처리 |

## 호출 방식

| 인자 | 동작 |
|------|------|
| 인자 없음 (`/작업저장`) | worktree 전체 스캔 + working/ 전체 일괄 저장 |
| `{작업명}` (`/작업저장 auth-refactor`) | 파일명 매칭 → 특정 작업만 저장 |

## ① worktree 정착 안내

진입 즉시 다음 확인:

```bash
git worktree list 2>/dev/null
```

- `~/.claude/worktrees/{session_id}-{slug}` 패턴 worktree 존재 시 → 사용자에게 정착 6단계 안내 (자동진행 §"정착 절차" 와 동일):

```bash
# 사용자 직접 실행 (! prefix)
! cd {원본 repo}
! git checkout {source-branch}
! git checkout -b feature/{source-branch}_{slug}
! git merge --ff-only wip/{session_id}-{slug}
! git worktree remove ~/.claude/worktrees/{session_id}-{slug}
! git branch -D wip/{session_id}-{slug}
```

**제약:**
- Claude 본체가 5~6 단계 직접 실행 시 `branch-enforce.sh` 차단. 안내만.
- source = `main` / `master` 시 정착 절대 금지 — PR 생성 안내로 대체.
- 정착 후 `git push` 도 사용자 직접.
- worktree 없으면 본 단계 SKIP.

## ② working/ 문서 마무리

`~/.claude/docs/working/YYYYMMDD/` 스캔. 인자 매칭 시 해당 파일만.

각 파일에 대해:

1. **Self-Critique 섹션 확인** — 미존재 시 Claude 본체가 직접 작성 (template 보강)
2. **잔여 작업 판정** — 다음 신호 종합:
   - 본문 미체크 박스 (`- [ ]`) 개수
   - 사용자 명시 잔여 (인자 또는 직전 응답 후속 권고 잔여)
   - `## TODO` / `## 잔여` / `## Follow-up` 섹션 존재 + 비어있지 않음
   - Self-Critique 항목 중 FAIL/WARN 미해결

## ③ 잔여 작업 기록 / 이동

### 분기 A — 잔여 0건

```markdown
Status: Done
```

(시작 라인) 부착 + `## Self-Critique` 보강 → `working-lifecycle.sh` PostToolUse hook 자동 발동 → `~/.claude/docs/{product}/tasks/YYYYMMDD/{작업명}/{yyyy-mm-dd}-{작업명}-unified.md` 이동.

### 분기 B — 잔여 ≥ 1건 (`/작업로드` 진입점)

```markdown
Status: Partial
```

(시작 라인) + 본문 끝에 `## 잔여 작업` 섹션 자동 부착:

```markdown
## 잔여 작업

- [ ] {잔여 항목 1} — 사유 / 다음 단계 1줄
- [ ] {잔여 항목 2} — 사유 / 다음 단계 1줄
...

**다음 세션 진입점:**
- `/작업로드` — 본 잔존 작업 자동 식별 + 재진입 안내
- `/작업로드 {작업명}` — 본 작업만 불러오기
- `/자동진행 {요약}` — 잔여 일괄 처리 (`/작업로드` 후 결정)
```

→ working/ 원본 유지 (이동 SKIP). 다음 세션에서 `/작업로드` 호출 → 잔여 항목 본문 표시 → 처리 후 다시 `/작업저장` 시 잔여 0건이면 자동 이동.

### REGISTRY 갱신 (2026-05-15 신설)

본 슬래시 ② working/ 문서 마무리 직후 `~/.claude/docs/working/REGISTRY.md` 갱신:

| 분기 | REGISTRY 처리 | 갱신 주체 |
|------|--------------|----------|
| 분기 A (Done) | entry 자동 제거 + state/sessions/{slug}/ lock 제거 | `working-lifecycle.sh` 가 mv 직후 자동 호출 (별도 액션 불필요) |
| 분기 B (Partial) | entry status=paused 명시 갱신 | `source ~/.claude/hooks/lib/registry-utils.sh && registry_update {slug} {sid} paused` 명시 호출 |

**충돌 정책:** 본 세션 외 다른 세션이 동일 slug 점유 (active) 중일 시 status=paused 갱신은 본 세션 sid entry 만 영향 — 다른 세션 active entry 는 보존.

## §3 Checkpoint 우선 적용

- worktree 정착 5~6 단계 = 비가역 (`git merge` / `git worktree remove` / `git branch -D`) → 사용자 명시 승인 후 직접 실행.
- working/ 문서 Status 변경 + 잔여 작업 섹션 추가 = Edit 도구 사용, `~/.claude/docs/working/` 경로는 Gate-0 면제.
- master/main 머지 절대 금지 룰 우선 — source 가 main/master 시 정착 안내 자체 생략, PR 안내 대체.

| `~/.claude/commands/작업저장.md` (본 파일) | 세션 마감 통합 저장 — worktree + 문서 + 잔여 동시 처리 |

## 호출 예

```
/작업저장                            ← 전체 (worktree 스캔 + working/ 전체)
/작업저장 auth-refactor              ← 특정 작업만
```

세션 마감 흐름 예시:

```
[사용자] /작업저장
   ↓
[Claude] ① worktree 스캔 → 1건 발견: ~/.claude/worktrees/631cd229-auth-refactor
        ② working/ 스캔 → 2건 발견:
           - 2026-05-14-hongcafe_global_backend-auth-refactor.md → 잔여 0건
           - 2026-05-14-claude-harness-hook-cleanup.md → 잔여 3건 (미체크 박스)
        ③ 처리:
           - auth-refactor → Status: Done 부착 → 자동 이동 (working-lifecycle 발동)
           - hook-cleanup → Status: Partial + ## 잔여 작업 섹션 추가 → working/ 유지
        ④ 정착 안내:
           "다음 명령을 직접 실행해주세요:
              ! cd /path/to/repo && git checkout production
              ! git checkout -b feature/production_auth-refactor
              ! git merge --ff-only wip/631cd229-auth-refactor
              ! git worktree remove ~/.claude/worktrees/631cd229-auth-refactor
              ! git branch -D wip/631cd229-auth-refactor"
        ⑤ 보고:
           - 이동 1건 / 잔여 보관 1건 / worktree 정착 대기 1건
           - 다음 세션 진입: /작업로드
```

## 차별점 (다른 슬래시와)

| 슬래시 | 시점 | 범위 |
|--------|------|------|
| `/자동진행` | 작업 시작·중간 | 묶음 승인 모드 진입 (실행) |

| **`/작업저장`** | **세션 마감 직전** | **worktree + 문서 + 잔여 통합 저장 (분기 A + B + worktree)** |
| **`/작업로드`** | **다음 세션 시작 직후** | **Status: Partial 잔존 작업 식별 + 재진입 안내** |
