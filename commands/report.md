오늘 날짜 기준 업무 리포트를 생성한다.

## 수행 절차

1. 아래 프로젝트 경로에서 `docs/tasks/` 디렉토리를 탐색한다:
   - `C:/Works/<PROJECT_BE>` → [백엔드]
   - `C:/Works/<PROJECT_FE>` → [프론트]
   - `C:/Works/infra` → [인프라]
   - 추가 프로젝트가 있으면 동일 패턴으로 탐색

2. 각 프로젝트의 `docs/tasks/history.md`와 오늘 날짜 요약(`YYYYMMDD/summary.md`)을 읽는다.

3. 오늘 날짜 요약이 없으면 `history.md`에서 가장 최근 항목을 확인한다.

4. `docs/tasks/YYYYMMDD/` 하위 디렉토리를 탐색하여 진행 상태를 판단한다:
   - `analyze.md`만 존재 → 분석 중 (30%)
   - `analyze.md` + `plan.md` → 계획 완료 (50%)
   - `analyze.md` + `plan.md` + `result.md` → 완료 (100%)
   - 디렉토리 없음 → 오늘 작업 없음

5. `docs/tasks/YYYYMMDD/todo.md` 파일이 있으면 미완료 항목도 포함한다.

6. 여러 프로젝트에 걸친 작업(CloudFront, 도메인, 공통 인프라 등)은 [글로벌]로 분류한다.

## 출력 형식

```
📋 업무 리포트 — YYYY.MM.DD

[글로벌]-[인프라]-EC2 PHP 설정 반영 (완료)
[글로벌]-[인프라]-Lambda Pub/Sub SDD 작성 (완료)
[글로벌]-[인프라]-Lambda 비즈니스 로직 구현 (30%)
[글로벌]-[백엔드]-API 인증 필터 추가 (50%)
[글로벌]-[프론트]-로그인 페이지 구현 (완료)
[글로벌]-[인프라]-CloudFront + HTTPS 적용 (미착수)
```

## 규칙

- 각 줄은 `[글로벌]-[백/프/인]-업무내용 (진행률%/완료/미착수)` 형식
- [글로벌]은 항상 앞에 붙이고, 하이픈(-)으로 구분, 두 번째 태그로 프로젝트 구분: [백엔드] 백엔드, [프론트] 프론트엔드, [인프라] 인프라
- 진행률은 task 디렉토리 산출물 기준으로 자동 판단
- todo 파일의 미완료 항목은 `(미착수)`로 표시
- 오늘 작업이 없는 프로젝트는 `작업 없음`으로 표시
- 프로젝트 경로가 존재하지 않으면 건너뛴다
- 출력은 간결하게, 한 줄에 하나의 업무
